# Explainer video

The 36-second film on `/ghid/asistent-ai`, with music. It is code, not a screen recording: a web
page whose whole state is a function of time, captured frame by frame. The soundtrack is code
too, synthesized on the same clock.

```bash
cd media/explainer-video
npm install
npm run render
```

That writes everything the site needs:

| Output | Used for |
|---|---|
| `public/media/asistent-ai/explainer.mp4` | H.264 1080p30, AAC 48 kHz at -16 LUFS, faststart |
| `public/media/asistent-ai/explainer-poster.jpg` | The player's poster, taken at `POSTER_AT` |
| `public/media/asistent-ai/explainer.ro.vtt` | Romanian captions |
| `src/app/components/guides/assistant-guide/explainer-transcript.generated.ts` | The transcript on the page |

The render takes a few minutes. Shortcuts while editing:

```bash
npm run render:fast          # 540p at 15 fps in out/draft.mp4, with sound, to check timing
npm run still -- 12,23       # single frames in out/still-*.png, to check layout
npm run audio                # the soundtrack alone in out/soundtrack.wav, to listen to it
node render.mjs --draft --audio other.wav   # out/draft.mp4 with another soundtrack
node render.mjs --draft --mute              # out/draft.mp4 without sound
```

## How it is put together

| File | What it holds |
|---|---|
| `src/timeline.mjs` | The beat grid (120 BPM, a bar is two seconds), scene timing, every caption and `HITS`, the moments picture and sound share. The WebVTT track and the page transcript are generated from it, so none of them can drift apart |
| `src/stage.html` | The scenes |
| `src/stage.css` | Layout, with tokens copied from `src/styles.scss` |
| `src/stage.js` | `window.seek(t)`, which computes every moving value from the time. Nothing animates on its own, so a render is reproducible |
| `src/soundtrack.mjs` | The music and sound effects, synthesized sample by sample from the same timeline. No dependencies, seeded noise, so it is reproducible too |
| `render.mjs` | Seeks, screenshots and pipes frames into ffmpeg; normalises the soundtrack in two passes and muxes it in |

## Rules

- This folder has its own `package.json` on purpose. The app neither installs nor builds it, and
  `playwright` and `ffmpeg-static` stay out of the site's dependencies.
- Fonts come from `public/fonts`, the same files the site self-hosts.
- Keep everything that matters above y=860. The bottom of the frame belongs to the captions.
- Every person, address, street and registration number in the film is invented. Keep it that way.
- The soundtrack is an original composition generated by `src/soundtrack.mjs`: no samples, no
  third-party recordings, so it carries no outside licence. A track swapped in with `--audio` must
  have a clear licence of its own.
- The film is understood without sound: every step is on screen and in the captions.
- The MCP server address never appears in a frame, so moving it to a custom domain needs no re-render.
